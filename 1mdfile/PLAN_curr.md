# UAV 导航课程训练方案

## 目标

按难度逐步训练策略：自由空间 -> 静态障碍物逐步增加 -> 动态障碍物逐步增加 -> 完整场景。

当前 `ppo_20260822_145608/checkpoint_2000.pt` 作为参考 baseline，课程训练从 C0 开始，前一阶段达标后再进入下一阶段。

## 固定条件

除障碍物数量外保持不变：`num_envs=1024`、`episode_length_s=60`、`physics_dt=1/60 s`、`decimation=1`、任务方向 `+Y -> -Y`、起点 X 按环境编号均匀分布、起飞高度 `0.5~2.5 m`、每轴速度 `[-2,2] m/s`、`goal_first=+120`、静态障碍物高度 `6 m`。

训练使用 Beta 随机采样动作，eval 使用 Beta 均值 deterministic 动作。静态地图使用固定 seed，正式 eval 固定使用 `seed=0、1、2`。

## 课程阶段

| 阶段 | 静态障碍物 | 动态障碍物 | 训练目标 | 晋级阈值 |
|---|---:|---:|---|---|
| C0 | 0 | 0 | 自由空间点到点导航 | 成功率 >= 95%，碰撞 <= 3%，超时 <= 3% |
| C1 | 30 | 0 | 基础静态绕障 | 成功率 >= 90%，碰撞 <= 8%，超时 <= 5% |
| C2 | 80 | 0 | 增加静态障碍密度 | 成功率 >= 85%，碰撞 <= 12%，超时 <= 5% |
| C3 | 150 | 0 | 接近完整静态地图 | 成功率 >= 82%，碰撞 <= 15%，超时 <= 5% |
| C4 | 200 | 0 | 完成静态障碍训练 | 成功率 >= 80%，碰撞 <= 18%，超时 <= 5% |
| C5 | 200 | 10 | 引入动态障碍物 | 成功率 >= 80%，总碰撞 <= 18%，动态碰撞 <= 12% |
| C6 | 200 | 30 | 增加动态障碍密度 | 成功率 >= 78%，总碰撞 <= 20%，动态碰撞 <= 15% |
| C7 | 200 | 60 | 接近完整动态场景 | 成功率 >= 76%，总碰撞 <= 22%，动态碰撞 <= 17% |
| C8 | 200 | 100 | 完整目标场景 | 成功率 >= 75%，总碰撞 <= 22%，动态碰撞 <= 18% |

所有阶段越界率必须 `<=3%`；超过 `5%` 时不能晋级。

## 单阶段流程

每阶段使用独立目录，例如 `runs/curr_C4_static200_dynamic000`。执行步骤：

1. 设置本阶段静态/动态障碍物数量。
2. C0 使用随机初始化；其余阶段加载上一阶段 checkpoint 的网络参数。
3. 先训练 `1000` iteration，每 `100` iteration 保存 checkpoint；未达标时最多延长到 `2000` iteration。
4. 训练窗口达标后运行独立 deterministic eval。
5. 训练和 eval 都达标才进入下一阶段。

当前 checkpoint 不保存 optimizer 状态，因此阶段切换时继承网络和 ValueNorm，使用新 optimizer；学习率和 PPO 超参数保持不变。

## 晋级判定

训练端统计最后 `100` 个 iteration 的所有 done episode，窗口至少包含 `500` 个 done；连续 3 个窗口都满足阶段阈值才算训练达标。

正式 eval 协议：

```text
num_envs = 1024
episodes_per_env = 1
action = deterministic Beta mean
seed = 0、1、2
```

三个 seed 的平均结果必须达到阶段阈值，任一 seed 不得比阶段目标低超过 10 个百分点。每次保存 `summary.json`、`episodes.csv` 和 `report.html`。

## 失败和回退

- 训练到 `2000` iteration 未达标：先检查观测、场景和碰撞判定，不立即修改奖励。
- 成功率低且碰撞率高：回退上一阶段确认低难度任务是否仍可学习。
- 碰撞下降但超时上升：判定避障信号过强，不晋级。
- 只有一个 seed 失败：增加重复评估，不根据单次结果改奖励。
- 新阶段连续两个窗口明显差于上一阶段：回退 checkpoint，降低障碍物数量。
- 奖励实验必须新建 run，每阶段最多做一次单变量奖励实验。

## 记录模板

```text
阶段：C?
静态/动态障碍物：?/ ?
初始化 checkpoint：...
训练 iteration：...
训练成功率/碰撞率/超时率/越界率：...
eval seed 0/1/2：...
是否晋级：是/否
主要失败原因：...
```

重点记录动态碰撞率。总成功率提高但动态碰撞率同时提高时，不能判定课程阶段成功。

## 最终验收

C8 完成后使用未参与训练的 seed，至少评估 `3072` 个 episode：

```text
平均成功率 >= 75%
平均总碰撞率 <= 22%
平均动态碰撞率 <= 18%
平均越界率 <= 3%
平均超时率 <= 5%
```

同时检查最差 seed。平均值达标但最差 seed 明显退化，说明泛化不足，需要增加动态障碍物状态随机化后重新训练。

## 实施顺序

```text
C0 自由空间
  -> C1/C2/C3/C4 静态障碍物逐级增加
  -> C5 少量动态障碍物
  -> C6/C7 动态障碍物逐级增加
  -> C8 完整场景
  -> 多 seed 最终验收
```
