## 2. MDP 架构

### Actions

- `uav_velocity`：3 维世界系速度指令 `[vx, vy, vz]`，经 VelocityController 转推力/力矩
- `global_obstacle_motion`：0 维动作项，每物理步推进动态障碍物；场景无集合时自动禁用

### Observations（全部转 goal frame，dict 结构）

| 组 | 形状 | 内容 |
|---|---|---|
| state | [N,8] | 目标方向(3) + 2D 距离(1) + z 距离(1) + 速度(3) |
| lidar | [N,1,36,4] | range - distance 归一化 |
| direction | [N,1,3] | 2D 任务方向（goal frame x 轴） |
| dynamic_obstacle | [N,1,5,10] | 最近 5 个障碍物（位置/距离/速度/尺寸类别），量程外清零 |

### Events

- `reset_nav_task`：四边界随机起点、对侧目标、yaw 朝向目标；起点/目标放在 ±22m（地图外 2m 平地，避免 spawn 在静态障碍内）

### Rewards（uav 权重）

progress +4、vel +0.5、static -6、dynamic -10、height -2、smooth -0.05、time -0.01；首达 +50、安全到达 +0.5、碰撞 -120

### Terminations

静态碰撞（LiDAR）、动态碰撞（全部障碍物几何距离）、高度越界（z<0.2 或 z>4.0）、成功、超时

## 3. 动态障碍物模块（mdp/dynamic.py）

分区结构：

```text
## 运动参数      GlobalObstacleMotionCfg
## 运动引擎      GlobalObstacleManager（锚点/航点/积分/写入）
## 外部接口      get / has_scene_entity / step helpers
## 框架接入      GlobalObstacleMotionAction + Cfg
## 场景配置生成  GlobalRigidObjectCollection + make_global_obstacle_collection_cfg
```

关键机制：

- 运动状态 `[1, M, ...]` 批量张量，每物理步一次写入 pose + velocity
- 有界随机航点：锚点 ±(1,1,0.4)m，速度 0.25~0.75 m/s，到达阈值 0.05m
- 懒初始化：第一个物理步从 default_object_state 读锚点、采样航点
- 不随场景重置：新进程 spawn + 懒初始化即复位
- count=0：make 函数返回 None，NavEnvCfg.__post_init__ 大开关关闭动作/观测/终止项

## 6. Agents 与算法架构方案

### 目录结构

```text
nav/tasks/manager_based/nav/agents/
  __init__.py      # gym 注册入口（ppo_cfg_entry_point / sac_cfg_entry_point）
  common.py        # 共享：obs_to_tensordict、FeatureExtractor、MLP、ReplayBuffer
  networks.py      # 共享网络：Actor / Critic（PPO 与 SAC 复用/继承）
  ppo.py           # PPO 算法类
  sac.py           # SAC 算法类
  ppo.yaml         # PPO 超参
  sac.yaml         # SAC 超参
```

### 算法层统一接口

```python
class BaseAlgorithm(nn.Module):
    def act(self, obs_td) -> TensorDict:    # 推理：action/log_prob/value/q
    def update(self, batch) -> dict:        # 学习：返回 loss 指标
    def save(self, path)
    def load(self, path)
```

- PPO.act：Beta 采样 → 归一化动作 → 世界系速度；返回 action/log_prob/value
- SAC.act：重参数化高斯 + tanh 收缩；训练带噪声、评测确定性

### 共享网络

- FeatureExtractor（共用）：lidar CNN + dynamic MLP + state 拼接 → feature [256]
- Actor：PPO 用 Beta；SAC 用 tanh squashed Gaussian，输出有界世界系速度
- Critic：PPO 单 value；SAC 双 Q + target 网络（soft update）

### PPO 要点（移植 uav）

```text
act:    feature → Beta.sample → vec_to_world
update: GAE（done=terminated|truncated，防自动重置自举）
        → advantage 归一化 → ValueNorm
        → 多 epoch + minibatch，actor/critic clip + entropy
存储:   num_steps_per_env 步一个 rollout（TensorDict）
```

### SAC 要点（新写）

```text
act:    mean/log_std → reparameterize → tanh → 世界系速度
update: ReplayBuffer 采样 minibatch
        → target Q = min(q1_t, q2_t)
        → 双 Q loss（MSE）→ actor loss（α log π − min Q）→ soft update
存储:   ReplayBuffer（obs/action/reward/next_obs/done）
```

### Trainer（scripts/train.py）

- `--algo` 选 ppo / sac；env + agent 按 yaml 创建
- PPO 循环：收集 rollout → agent.update → 日志/checkpoint
- SAC 循环：act → step → 存 replay → 每 N 步 update → 日志/checkpoint
- 共用 EpisodeStatistics、wandb、checkpoint

### PPO / SAC 差异

| | PPO | SAC |
|---|---|---|
| 数据 | rollout 用完即弃 | ReplayBuffer 循环复用 |
| 更新频率 | 每 rollout 一次 | 每 N 步采样更新 |
| 动作分布 | Beta（有界） | 高斯 + tanh（有界） |
| Critic | 单 value + GAE | 双 Q + target + soft update |
| ValueNorm | 有 | 不用（可 reward scaling） |

### 实现顺序

1. common.py（工具 + FeatureExtractor + ReplayBuffer）
2. ppo.py（移植 uav + 接口统一）
3. scripts/train.py（先 PPO，跑通冒烟）
4. sac.py + sac.yaml
5. gym 注册 entry point 更新
6. PPO 小规模验证（16 env），再 SAC 对照
