# 2026-08-14 PPO 实现与训练方案

## 1. 目标

实现第一个自定义 PPO 版本并跑通训练冒烟；SAC 暂不做。

## 2. 新增文件

## 3. PPO 结构

```text
FeatureExtractor（共享）
  lidar [1,36,4] → CNN
  dynamic [1,5,10] → MLP
  state [8] → 直接拼
  → feature [256]

Actor：Beta 分布 → 归一化动作 [0,1] → ±2 m/s → vec_to_world 世界系速度
Critic：feature → value

update：
  GAE（done=terminated|truncated，防跨回合自举）
  → advantage 归一化 → ValueNorm
  → 4 epoch × 16 minibatch
  → ratio = exp(new_log_prob - old_log_prob)
  → actor clip + critic clip + entropy
```

## 4. 关键设计

- **两次特征提取**：收集时提一次（出动作，结果存 transition）；update 时对 rollout 里的原始 obs 重新提（网络已更新，必须重算 new_log_prob）；
- **transition 只存原始 obs + action/log_prob/value，不存 feature**；
- **env 与算法解耦**：env 只收 tensor、返回 dict；trainer 负责 obs_to_tensordict 包装和 action 提取；
- **超参（ppo.yaml）**：lr 5e-4、clip 0.1、action_limit 2.0、gamma 0.99、gae_lambda 0.95、epoch 4、minibatch 16、frame_num 32。

## 5. 踩坑记录

1. `env.single_observation_space` 不存在：Isaac Lab 的 gym.make 返回 OrderEnforcing 包装，用 `env.observation_space`；
2. observation_space 是带 batch 维的空间（lidar shape = (16,1,36,4)）：取形状时去掉第一维：
   `shape[1:]` / `shape[-1]`；
3. 日志目录固定到 nav 项目根（`Path(__file__).resolve().parents[1] / runs`），不写到 IsaacLab。
