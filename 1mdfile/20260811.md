## 2. 物理步链（训练时每步执行）

```text
env.step(actions)
  ├─ action_manager.process_action(actions)          # 每 env step 一次
  │
  └─ for _ in range(decimation=2):                   # 每个物理步
       action_manager.apply_action()
         ├─ UavVelocityAction.apply_actions()        # 无人机动作（见第 3 节）
         └─ GlobalObstacleMotionAction.apply_actions()
              └─ GlobalObstacleManager.step(physics_dt)
                   ├─ 首次：懒初始化（读锚点、采样第一批航点）
                   ├─ 到达航点 → 重采样（±1,1,0.4m，0.25~0.75 m/s）
                   ├─ 直线积分 → 更新 position / linear_velocity
                   └─ 批量写入 pose + velocity 到 PhysX
       scene.write_data_to_sim()                     # wrench 和障碍物状态真正进 PhysX
       sim.step()
       scene.update(dt)
  ├─ 终止判定（time_out）
  ├─ 奖励计算（alive）
  └─ 部分重置（见第 4 节）
```

## 3. 无人机动作链路

### 第一段：策略输出 → 动作缓冲（每 env step 一次，60Hz）

```text
trainer 生成 action [N, 3]（世界系 [vx, vy, vz]）
  └─ ActionManager.process_action(action)
       └─ 按 term 切分，uav_velocity 分到 action[:, 0:3]
            └─ UavVelocityAction.process_actions()
                 ├─ _raw_actions[:] = 原始动作
                 ├─ processed = raw * scale
                 ├─ 若 max_velocity 设置 → clamp(±max_velocity)
                 └─ _processed_actions[:] = processed
```

### 第二段：每个物理步应用动作（120Hz）

```text
ActionManager.apply_action()
  └─ UavVelocityAction.apply_actions()
       └─ VelocityController.apply_action(processed_actions)   [N,3]
            ├─ 1. 读当前状态
            │     robot.data.root_state_w → pos / quat / lin_vel_w / ang_vel_w
            │     再转到机体系 lin_vel_b / ang_vel_b
            ├─ 2. 算 yaw 指令
            │     velocity_vector：朝水平速度方向转（yaw_rate_limit 限速）
            │     command = [yaw, vx, vy, vz]                  [N,4]
            ├─ 3. LVController.compute(state, command)
            │     a. 速度环
            │        误差 = cmd_speed - lin_vel_w
            │        → 加速度限幅（max_feedback_accel=20）
            │        → des_F = m × (a - g)                    # 需要的合力
            │        → 期望机体 z 轴推力（des_F 转到机体系）
            │     b. 姿态环
            │        期望 yaw（b1）+ 期望推力方向（b3）→ 期望姿态 R_des
            │        → 姿态误差 → 期望 body rate（pose_gain）
            │     c. 推力一阶低通（thrust_ctrl_delay=0.03s，模拟电机延迟）
            │     d. 角速度环
            │        误差 = 期望 body rate - ang_vel_b
            │        → torque = I×(rate_gain×err) + 陀螺力矩项
            │     → 输出 [total_thrust, torque_x, torque_y, torque_z]   [N,4]
            ├─ 4. clamp 到物理上限（4×转子最大推力、最大力矩）
            ├─ 5. 填 force_body [N,1,3]（z=推力）、torque_body [N,1,3]
            └─ 6. robot.permanent_wrench_composer.set_forces_and_torques(...)
                  # 机体系 wrench，作用在 body 刚体
```

### 第三段：写入仿真并推进

```text
scene.write_data_to_sim()
  └─ Articulation 把 permanent wrench 通过 PhysX view 应用（body frame）
sim.step()          # PhysX 积分：wrench → 加速度 → 速度/位置更新
scene.update(dt)    # robot.data 回读新状态，供下一步控制使用
```

### 动作链路要点

- 频率差：动作指令每 60Hz 更新一次（`process_actions`），控制器每 120Hz 执行一次（`apply_actions`）。
- 坐标系：策略给世界系速度；控制器内部把期望力转到机体系求推力，力矩在机体系算，wrench 按机体系写入。
- 写入时机：`VelocityController` 只把 wrench 放进 `permanent_wrench_composer`，真正进 PhysX 发生在 `scene.write_data_to_sim()`；`apply_actions` 必须先于 write 执行（框架顺序保证）。

## 4. 重置链

```text
某架无人机 episode 终止
  └─ _reset_idx(部分 env_ids)
       ├─ robot.reset(env_ids)                        # 无人机缓冲
       ├─ GlobalRigidObjectCollection.reset() → pass  # 障碍物完全不受影响
       ├─ UavVelocityAction.reset(env_ids)
       │    ├─ 清速度指令缓冲
       │    └─ VelocityController.reset_idx(env_ids)
       │         ├─ LVController 状态清零，gross_thrust 置为悬停推力
       │         └─ permanent wrench 清零（无残留推力）
       └─ GlobalObstacleMotionAction.reset() → pass   # 障碍物继续运动
```

## 5. 动态障碍物生命周期

```text
进程启动 → spawn 在锚点
  → 第一个物理步懒初始化（锚点 + 采样航点）
  → 之后每个物理步持续推进（重采样/积分/写入）
  → 训练期间无人机怎么重置都不碰它
  → 进程结束销毁
```

## 6. 设计决定与已知问题

### 设计决定

- 动态障碍物不重置：新进程 + 懒初始化即复位。
- 碰撞语义：无碰撞体资产 + LiDAR/几何距离判断；真实 PhysX 接触待烟雾测试后再定。

### 已知问题

- 场景使用 `DRONE_CFG`（带碰撞体），需切换 `DRONE_NO_COLLIDER_CFG`。
- 动态障碍物默认开启碰撞，需改为 `collision_enabled=False`。
- 动态障碍物固定 z=1.5m，可能嵌进 6m 静态障碍物。
- 本地 shell 无 GPU，可视化/冒烟需在有 GPU 的 Isaac 环境进行。

## 7. 悬停抖动修复

- 现象：`zero_agent.py` 里无人机悬停一直抖动，`test_drone_dynamics.py` 却非常稳。
- 原因：测试脚本显式开启了 `sim_cfg.physx.enable_external_forces_every_iteration = True`，而 Manager 环境的 `SimulationCfg` 默认是 **False**。TGS 求解器下外力只在部分迭代生效，速度反馈噪声大，控制器拿噪声速度做反馈导致抖动。
- 修复：在 `NavEnvCfg.__post_init__` 中加一行：

```python
self.sim.physx.enable_external_forces_every_iteration = True
```

- 简单理解：推力每次都生效 → 速度读数平稳 → 控制器不瞎忙 → 无人机不抖。
