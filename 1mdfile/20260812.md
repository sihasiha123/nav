# 2026-08-12 场景之后：阶段 4 导航 MDP

## 当前状态

- 场景已构建并可视化完成（共享地图、1024 无人机、100 个全局动态障碍物）。
- 动作已接好：`UavVelocityAction`（3 维速度）+ `GlobalObstacleMotionAction`（障碍物每物理步运动）。
- MDP 仍是占位：观测 6 维、无事件、alive 奖励、timeout 终止。

## 下一步：导航 MDP（参考 uav direct 版移植）

uav 项目顺序：场景 → reset → 观测 → 奖励 → 终止 → 训练。nav 接下来完成阶段 4。

### 1. 加 LiDAR 到场景（观测前置依赖）

- 从 uav 抄 `RayCasterCfg`：`prim_path="/World/envs/env_.*/Robot/body"`、
  `ray_alignment="yaw"`、`mesh_prim_paths=["/World/ground"]`。
- 36 水平 x 4 垂直光束，`vertical_fov_range=(-10, 20)`，量程 4m。
- 加到 `NavSceneCfg`，观测里读 `lidar.data.ray_hits_w`。

### 2. Reset 逻辑（uav `_reset_idx` → Manager reset 事件）

- 新建 `mdp/events.py`：四边界随机起点、对侧目标、yaw 朝向目标。
- 写 root pose/velocity、记录 `height_range`、清历史缓冲。
- 注册为 `EventCfg` 中 `mode="reset"` 的事件。

### 3. 观测（uav `_get_observations` → ObsTerm）

- `state [N,8]`：target_dir_goal(3) + distance_2d(1) + distance_z(1) + drone_vel_goal(3)。
- `lidar [N,1,36,4]`：`range - distance` 归一化。
- `direction [N,1,3]`：2D 任务方向。
- `dynamic_obstacle [N,1,5,10]`：最近 5 个障碍物（rel_pos_unit、dist_2d、dist_z、vel_goal、size 类别），range_mask 清零。
- 全部转 goal frame；从 uav 搬 `vec_to_new_frame`；动态观测接 `GlobalObstacleManager`。

### 4. 奖励（uav `_get_rewards` → RewardsCfg）

- 重写 `mdp/rewards.py`（当前仍是 Cartpole 残留）。
- uav 权重：4.0 progress + 0.5 vel（clamp ±2）− 6 static² − 10 dynamic² − 2 height² − 0.05 smooth − 0.01 time。
- 首达目标（安全）+50；安全到达持续 +0.5；碰撞 −120。

### 5. 终止（uav `_get_dones` → TerminationsCfg）

- 静态碰撞：`lidar.amax > lidar_range - 0.3`。
- 动态碰撞：几何距离（检查全部障碍物，不只是最近 5 个）。
- 越界：`z < 0.2` 或 `z > 4.0`；成功：`distance < goal_radius` 且无碰撞；超时。

### 6. 收尾

- Gym 注册名改为 `Nav-Drone-PointNav-v0`。
- 跑 zero/random agent 验证。
- 用 `scripts/rsl_rl/train.py` 短训练冒烟。

## 建议实施顺序

LiDAR → reset 事件 → 观测 → 终止 → 奖励 → 注册名 → 冒烟。
